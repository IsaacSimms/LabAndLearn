This directory is a set of ntoes taken, takeways gained, and knowledge aquired from reading the professional practitioner book "Designing Distributed Systems 2nd Edition" by Brendan Burns.

Designing Distributed Systems 2nd Edition is a highly technical book that focuses on reusable, container-native distributed system patterns and infrastructure insights.
